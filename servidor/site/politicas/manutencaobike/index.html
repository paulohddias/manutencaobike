Política de Privacidade

Manutenção Bike · Via Vale Sistemas · Atualizada em 08/11/2026

Quem somos

O aplicativo Manutenção Bike é desenvolvido pela Via Vale Sistemas, responsável pelo tratamento dos dados descritos aqui, nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018 – LGPD).

Dados que ficam no seu celular

Bikes, peças, serviços, custos, quilometragem e fotos que você cadastra ficam guardados no próprio aparelho. As fotos escolhidas na galeria ou tiradas pela câmera são copiadas, reduzidas, para a área privada do app; o app não acessa outras fotos.

Conexão com o Strava

Se você decidir conectar sua conta do Strava, o app recebe, com a sua autorização:

  • seu nome e sobrenome no Strava;
  • a lista das suas bikes (nome, marca, modelo e distância percorrida).

Esses dados são usados apenas para importar e atualizar a quilometragem das suas bikes. Os tokens de acesso do Strava ficam guardados no seu celular. Nosso servidor só intermedeia a troca e a renovação desses tokens e registra o número de identificação do seu atleta para vincular seus backups — ele não armazena os tokens nem suas atividades.

Você pode desconectar o Strava a qualquer momento pelo menu do app ou revogar o acesso em strava.com/settings/apps.

Backup na nuvem

Ao usar o backup, uma cópia dos dados do app (incluindo as fotos das bikes) é enviada por conexão criptografada (HTTPS) para servidores da Via Vale Sistemas, hospedados no Brasil. Guardamos no máximo as 5 cópias mais recentes de cada usuário. O backup automático pode ser desligado na tela Backup na nuvem.

O que não fazemos

  • Não vendemos nem compartilhamos seus dados com terceiros.
  • Não usamos seus dados para publicidade.
  • Não coletamos localização, contatos nem dados de uso para análise.
  • Não usamos dados do Strava para nenhuma finalidade além das funções do app.

Segurança

Toda comunicação com nosso servidor usa HTTPS. A sessão de cada usuário é identificada por um código aleatório, do qual guardamos apenas uma versão criptografada (hash). Os arquivos de backup ficam fora de qualquer área pública do servidor.

Exclusão dos seus dados

Você pode apagar todos os seus dados do nosso servidor pelo próprio app ou solicitar por e-mail. Veja o passo a passo em Exclusão de dados. Ao desinstalar o app, os dados guardados no celular são apagados pelo Android.

Seus direitos

Pela LGPD, você pode pedir confirmação, acesso, correção, portabilidade e exclusão dos seus dados, além de revogar consentimentos. Para isso, escreva para EMAIL_DE_CONTATO.
